# Contributing

Thanks for helping grow Awesome System Verification.

- One link per pull request where possible.
- Format: `- [Name](URL) - Short description.`
- Add to the most relevant section; keep alphabetical order only if the section already uses it.
- Links must be live, free to read (or clearly marked), and about verification.
- No marketing fluff. Explain what the resource is and why it helps.

Maintained by [Carver Agents](https://carveragents.ai) and [Testfold](https://testfold.ai).
